# 파이 노드 0보상 점검 키트

## 사용법 (노드 PC에서)
1. 이 폴더(`PiNodeCheck.ps1`, `노드점검_실행.bat`)를 USB(F:)에 복사
2. `노드점검_실행.bat` → 마우스 오른쪽 → **관리자 권한으로 실행**
3. USB에 `PiNodeReport_컴퓨터이름_날짜.txt` 생성 → 이 파일 내용을 Claude에게 붙여넣기

스크립트는 **읽기 전용**입니다. 설정을 바꾸지 않고 상태만 기록합니다.

## 점검 항목
| # | 항목 | 0보상과의 관계 |
|---|------|----------------|
| 2 | 가동시간·시계 동기화 | 재부팅/정전, 시계 오차 → 합의 참여 실패 |
| 3 | 절전 설정 | 절전 진입 시 노드 중단 |
| 4 | Pi Desktop / Docker 버전 | 구버전은 메인넷 연결 끊김(Protocol v26, 2026-08-11 마감) |
| 5–6 | Docker·컨테이너·동기화(`Synced!`) | 화면은 켜져 있어도 컨테이너 재시작 반복·미동기화 |
| 7–8 | 31400–31409 수신·방화벽 | 포트 닫힘 → 가용성 점수 하락 |
| 9 | 이중 NAT(유플러스 모뎀+개인 공유기) | 한쪽만 포트포워딩하면 외부에서 닫힘 |
| 10 | 공인 IP 포트 접속 | 참고용 (정확한 판정은 휴대폰 LTE로 외부 포트체커) |

## 코드로 확인 불가한 계정 쪽 항목
- 노드 PC의 Pi 로그인 계정 = 아들 휴대폰 Pi 앱 계정인지
- 휴대폰에서 24시간마다 채굴 버튼을 눌렀는지 (세션이 꺼진 동안엔 노드 보너스 포함 모든 채굴 보상 중단)
- KYC 완료·메인넷 이전 여부
